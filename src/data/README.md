# Arelbot local data

`turkish_cities.json` is a normalized snapshot of 81 provinces and 973
districts. It is generated by `scripts/build_city_data.py` from the
MIT-licensed `turkiye-data` project and the official BTK area-code list.

The snapshot stores a generated version and SHA-256 checksum. Runtime loading
verifies that checksum before building lookup indexes; a failed verification
stops startup instead of serving a partially modified directory.

The update script keeps the previous JSON as `turkish_cities.json.bak` so a
reviewed snapshot can be restored without a network request.

The runtime never downloads this file. Update it deliberately, review the
diff, update the generated date and keep the source metadata in the JSON.
